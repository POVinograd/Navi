# Navi

**Navi** — персональное Android-приложение для отслеживания привычек, повседневной активности, ведения дневника и мониторинга окружающей среды.

Проект разрабатывается на **Kotlin** с использованием **Jetpack Compose**.

Основная цель — создать персональный мобильный трекер с интерфейсом, вдохновлённым главным экраном PSP, гибкой системой оформления и возможностью дальнейшего расширения функциональности.

## Основные возможности

### 1. Главный трекер
- Календарь выполненных привычек.
- Просмотр прогресса за день и за длительные периоды.
- Статистика выполнения привычек.
- Фильтрация по привычкам.
- Индивидуальная статистика каждой привычки.

### 2. Управление привычками
- Создание, редактирование, архивация, восстановление и удаление привычек.
- Настройка названий, описаний, иконок и цветов.
- Гибкая настройка расписания, целей и периодичности.
- Отметка и редактирование выполнения привычек.
- Отдельная история выполнения и история изменения параметров привычек.

### 3. Вода и калории
- Учёт ежедневного потребления воды.
- Настройка дневной нормы воды.
- Учёт потреблённых калорий.
- Настройка дневной нормы калорий.
- Просмотр дневного прогресса и истории.
- Возможность редактировать и удалять отдельные записи калорий.

### 4. Личный дневник
- Создание текстовых записей.
- Отслеживание настроения.
- Пользовательские теги для организации записей.

### 5. Мониторинг окружающей среды
- Отображение температуры.
- Отображение относительной влажности воздуха.
- Мониторинг концентрации CO₂.
- Локальное подключение к микроконтроллеру ESP32 через Wi-Fi.
- Отображение состояния соединения и времени последнего обновления данных.

## Дизайн и персонализация

- Радиальная нижняя навигация с анимациями.
- Несколько визуальных тем оформления.
- Планируемые встроенные темы: **Gen X Soft Club** и **Frutiger Aero**.
- Расширяемая архитектура тем.
- Возможность создания пользовательских тем.
- Звуковые эффекты интерфейса, вдохновлённые атмосферой PSP.

## Архитектура

Приложение проектируется с учётом модульности, расширяемости и удобства дальнейшей поддержки.

Предусматривается разделение на следующие слои и компоненты:

- **Presentation** — пользовательский интерфейс и логика представления.
- **Domain** — бизнес-логика приложения.
- **Data** — работа с данными и репозиториями.
- **Design System** — общие UI-компоненты и система тем.
- **Navigation** — навигация между разделами.
- **Audio** — управление звуковыми эффектами.

Одна из основных концепций проекта — **Local-first**: пользовательские данные хранятся локально на устройстве без необходимости подключения к интернету.

Мониторинг окружающей среды будет работать через локальную сеть Wi-Fi с использованием ESP32, без необходимости во внешнем облачном сервере.
